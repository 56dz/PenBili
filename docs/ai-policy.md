# 关于 AI 参与开发与界面文案（PStore 规则 4）

PStore 的新规第 4 条要求去掉「AI 味」表述，并删掉多余的状态提示。本文说明
PenBili 的实际情况、已经做了什么，以及为什么某些看起来像提示的文案保留了。

## 1. AI 参与了什么

如实说明：**这个项目的界面代码与 native 播放子系统，主要是在 AI 编程助手的
协作下完成的**，作者负责需求、真机验证、根因判定与最终取舍。

AI 协作最容易出问题的地方恰好是规则 4 点名的两处，所以下面逐项交代处理结果。

## 2. 界面上没有 emoji、没有装饰符号

会渲染到屏幕的字符串里**没有 emoji**，也没有制表符画框、方块字符之类的装饰。
全仓 `→` 出现 321 次、`①` 12 次、`≈` 11 次，但它们**全部在代码注释和日志字符串里**
（日志只在 `/tmp/pb2.log`，用户看不到），模板区一处也没有。

界面上唯一的几何符号是评论区点赞数的前缀 `▲`（`src/pages/index/index.vue:2600`）。
这一类单色符号是否会被渲染成方框，**不能按 Unicode 码段推断，必须在真机上看**，
所以单独做了验证：

| 符号 | X6 Pro 实测 | 位置 |
| --- | --- | --- |
| `▲` U+25B2 | 正常渲染为实心三角 | 评论区「▲ 297」 |
| `‹` U+2039 | 正常渲染 | 收藏夹「‹ 退出」 |
| `…` U+2026 | 正常渲染 | 「加载中…」「定位中…」 |

（对照：同一个运行时下 `⌫` U+232B 会渲染成 tofu 方框，所以本项目不用它。）

## 3. 删掉的多余提示

规则 4 明确说「大家都知道的玩法说明、『等待操作』一类可以删掉」。已删/已改：

| 原来 | 现在 | 理由 |
| --- | --- | --- |
| `当前不可控制（取流中…）` | 静默忽略 | 未起播时点视频区本来就没有动作；把内部状态名 `取流中…` 抛给用户是典型的机器解释 |
| `未登录时视频可能无法正常显示，登录后体验更完整` | `未登录 · 部分视频可能看不到` | 原句是产品经理式长句，266px 一行放不下还换行 |
| `当前 vX.Y.Z · 两个按钮都是直连：GitCode / GitHub` | `当前 vX.Y.Z · 直连 GitCode / GitHub` | 「两个按钮都是直连」在解释显而易见的东西 |

## 4. 保留的状态提示，以及为什么它们不是「AI 味」

判据：**这条提示是否在告诉用户一件他从画面上看不出来、且需要他决策的事。**
按这个标准，下列提示全部保留：

| 提示 | 用户看不出来的原因 |
| --- | --- |
| `加载中…` | 视频区是透明挖孔，画面没到时那块是纯黑，与「卡死」无法区分 |
| `定位中…` | 进度条已经跳到目标位置，但首帧要 200~2500ms 才到，期间 thumb 与画面必然不一致 |
| `音画不同步，正在恢复…` | 播放器在自动重建管线，用户只会觉得「为什么突然顿一下」 |
| `画面已停滞，可返回重进` | 自愈配额用完，需要用户决策（返回 / 继续等） |
| `网络不稳定，正在重连…` | 直播断流后会自己退避重连，不提示的话用户以为播放器死了 |
| `无声：音频设备被占用，已静音播放` | 画面正常但没声音，原因（别的进程占了音频）用户无从得知 |
| `起播失败 · 可返回重试` | 终态，必须给下一步动作 |

这些提示都是**一句话、说结果、给动作**，没有「正在努力为你…」这类拟人表述，
也没有把内部状态名（`resyncing` / `seekPending` / `AUDIO_STALL`）直接抛给用户。

## 5. 没有一条提示在解释「怎么玩」

- 首页没有新手引导、没有「点击卡片开始观看」这类说明 —— 卡片本身有封面和标题。
- 播放页没有「点击视频区可暂停」提示 —— 这是触屏播放器的公共直觉。
- 「我的」页没有功能说明段落，只有 `画质 720p 60fps ›` 这种**当前值 + 可点**的行。

## 6. 遗留的取舍

`关于` 区有一句免责声明：
`第三方客户端，与哔哩哔哩无隶属关系；所有内容版权归原作者及平台所有`

它不是状态提示，是法律声明，必须保留。放在「我的」页最底部，不干扰主流程。

## 7. 如何复核

```bash
# 界面字面量（模板里 >文字< 的部分）
#   人工看一遍，确认没有「正在为你/请稍候，马上就好」这类表述
grep -o ">[^<>{}]\{2,60\}<" src/pages/index/index.vue

# 模板里有没有 emoji（结果应为空）
grep -rnP "[\x{1F300}-\x{1FAFF}\x{2600}-\x{27BF}]" src/pages/ src/styles/
```
