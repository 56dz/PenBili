# PenBili

**有道词典笔 X5 上的哔哩哔哩播放器**（Falcon / QuickJS mini-app，Vue 2 SFC）。本发布以仓库 `v2.7.0` 源码为基线，版本号为 `2.8.2`。

在逻辑分辨率 800×254 的设备屏幕上提供推荐流、DASH 播放、弹幕、评论浏览/发表、TV 协议扫码登录与播放历史。

## 功能

- **播放**：DASH 分离视频与 AAC 音轨，当前请求 360p（id16）并优先选择 AVC；必要时回退单文件流；按视频实际宽高信箱适配，并记录播放历史。
- **音画同步**：轻微漂移时平滑追赶；音频领先超过 1 秒时只重启视频流并重新对齐，音频不中断；首帧等待有 15 秒上限，失败后自动恢复。
- **弹幕**：右栏独立面板（标题「弹幕」+ 每条一个框）竖向滚动，新条目自底部进入、整列上移。弹幕走独立的 `seg.so` protobuf 分段接口，按 6 分钟一包懒加载并缓存；渲染在 UI 层做普通文本，**不烧进视频帧**，不占解码预算。同一条弹幕按 id 去重，同一文本在可见窗口内也只保留一条。
  - 面板用**固定槽位**渲染（恒定 9 个框、key 固定），更新时只改文字、不增删节点。
  - **画面不健康时不重绘弹幕面板**（视频流重启中 / 停帧 >400ms / 本 tick 无新帧）：
    真机像素级实测，面板重绘会把视频区擦成黑色；正常播放时下一帧会补回来（只闪一下），
    但视频流重启期间无帧可补 → 持续黑屏 0.4~2.4s。加此保护后黑屏占比 16.4% → 0%。
  - **画面不健康时不重绘弹幕面板**（视频流重启中 / 停帧 >400ms / 本 tick 无新帧）：
    真机像素级实测，面板重绘会把视频区擦成黑色，正常播放时下一帧会补回来（只闪一下），
    但视频重启期间无帧可补 → 持续黑屏 0.4~2.4s。加此保护后黑屏占比 16.4% → 0%。
  - 每个分包最多解析 600 条（`DM_MAX_ITEMS_PER_SEG`）。这不是显示上限而是**稳定性红线**：真机实测部分稿件的分包可达 3.5MB / 上万条，全量解析会让 QuickJS 崩溃；包内顺序近似随机，取前 600 条仍覆盖整个 6 分钟时间轴。
- **网络抖动缓冲**：FFmpeg 输入线程预取压缩数据包（视频队列 300、音频队列 700）；它不是解码后的视频帧缓存，也不保证所有网络条件下固定 15 秒可用缓冲。
- **音频**：独立解码进程与音频环形缓冲，支持设备默认输出和 A2DP 音频路由。
- **评论**：分页浏览、子回复、系统输入法发表评论；评论面板打开时维持音频播放并避免视频闪烁。
- **登录**：TV 协议扫码登录、登录态持久化、过期检查与刷新。
- **列表与搜索**：推荐、热门和关键词视频搜索。

当前版本不提供直播和专栏图文阅读。

### 播放页布局

左栏自上而下为：标题、作者、评论区入口、返回列表、暂停/开始、进度与状态；中列为视频；右列为弹幕。

> 弹幕曾在 v2.7.0 被移除，原因是当时把弹幕用 native `drawtext` 逐帧烧进视频帧，占掉约 20% 解码预算，弱稿件软解跌破实时而卡顿。`2.8.0` 改为在 UI 层渲染文本（与评论列表同一条路径），实测起播漂移曲线与关闭弹幕时一致，不再影响播放。

## 性能诊断记录

一次约 4.5 分钟的播放采样（253 个样本）中，播放稳定期未观察到超过 1 秒的停帧；超过 1 秒的停顿出现在流启动或首帧恢复阶段。该轮中视频解码约占单核 55–81%，应用进程约 5%，全机约 25%。这说明该样本中的停顿更像首帧/流启动等待，而非持续的解码饱和；不同视频和网络下结果可能不同。

`2.7.1` 真机自检（有道 X5，DASH 360p / AVC）实测：首帧约 1.1 秒；稳定播放期音画漂移 2–36 ms、重同步 0 次、缓冲约 0.56 秒；±20 秒定位后约 1.5 秒恢复出帧。音频首帧会等待视频首帧后同步开播，避免起播瞬间的唇音错位。

`2.8.0` 弹幕开销对照实验（同一稿件、同一网络，仅切换弹幕开关）：开与关的起播漂移曲线基本重合——都在起播约 20–30 秒内涨到 1.8–2.2 秒并触发 2 次视频流重同步，随后稳定在 5–90 ms。可见该稿件起播期的漂移来自码率（约 545 kbps）贴近设备带宽上限（实测约 646 kbps），与弹幕无关；弹幕只在 UI 层每秒最多追加 2 行文本，不参与解码。

## 构建与测试

前置：Node.js 18+、有道小程序打包器 **aiot-vue-cli**（1.0.32 验证）；重建 native 库另需 Zig（`arm-linux-gnueabihf.2.23` target）。

```bash
npm ci
npm test                    # 97 条逻辑、协议、几何与弹幕回归测试
node test/qr_login_test.js  # 21 条登录协议测试

# 打包 AMR（QuickJS 生产包）
npm run build

# 可选：从 native 源码重建库
# PowerShell: $env:ZIG_EXE = 'C:\path\to\zig.exe'; npm run native
```

## 安装与真机自检

具体命令以设备上的 `miniapp_cli --help` 为准：

```bash
adb push PenBili.amr /tmp/PenBili.amr
adb shell miniapp_cli install /tmp/PenBili.amr
adb shell miniapp_cli start 8002026091900004 --index
```

本地部署、自检与截图采集：`npm run deploy`（依赖 ADB 可访问设备）。
